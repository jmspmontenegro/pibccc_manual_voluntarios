# Manual do Voluntário — Turma de Primeira

Este projeto consiste em um manual digital interativo para os voluntários do ministério infantil **Turma de Primeira**, da **PIB Curitiba (Campus Campo Comprido)**. O objetivo é fornecer um guia centralizado e de fácil acesso para a organização de eventos, logística, comunicação e uso dos recursos da igreja.

## 🚀 Funcionalidades

- **Navegação Intuitiva**: Menu lateral categorizado para acesso rápido a informações sobre eventos, compras, logística e sistema.
- **Checklist Interativo**: Lista de verificação para eventos com acompanhamento de progresso em tempo real.
- **Modo de Impressão**: Otimizado para imprimir apenas o checklist em uma folha A4 limpa e organizada.
- **Design Responsivo**: Totalmente acessível via smartphones e tablets para consulta rápida durante os eventos.
- **Identidade Visual**: Cores e tipografia modernas (Nunito e Playfair Display) que refletem o acolhimento do ministério.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3 (Vanilla)**: Estilização personalizada, incluindo:
  - Layout flexbox e CSS Grid.
  - Variáveis CSS para fácil manutenção de cores.
  - Media Queries para responsividade.
  - Estilos específicos para impressão (`@media print`).
- **JavaScript (Vanilla)**: Lógica simples para:
  - Alternância do menu lateral (mobile).
  - Gerenciamento interativo do checklist.
  - Animações de scroll ("fade-in").

## 📂 Estrutura do Projeto

O projeto é mantido em um único arquivo para facilitar a distribuição e o acesso offline:

- `index.html`: Contém toda a estrutura, estilos (CSS) e lógica (JS).

## 📖 Como Usar

1. Clone este repositório ou baixe o arquivo `index.html`.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Firefox, Edge, Safari).
3. Utilize o menu lateral para navegar entre as seções.
4. Para imprimir o checklist, clique no botão **"🖨️ Imprimir Checklist"** localizado na seção 2.

## 🤝 Contribuições e Manutenção

As diretrizes contidas neste manual seguem os padrões estabelecidos pela liderança do ministério infantil e pela secretaria da **PIB Curitiba (Campus Campo Comprido)**.
