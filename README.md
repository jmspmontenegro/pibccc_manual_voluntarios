# Manual do Voluntário — Start

Este é o repositório do **Manual do Voluntário** do Start (Ministério Infantil da PIB Curitiba - Campus Campo Comprido). O projeto consiste em uma aplicação web estática (Single Page Application) projetada para ser um guia completo, interativo e acessível para todos os voluntários.

## 🚀 Funcionalidades

- **Interface Premium:** Design moderno com foco em legibilidade, utilizando tipografia elegante (Playfair Display e Nunito) e uma paleta de cores harmoniosa.
- **Totalmente Responsivo:** Otimizado para visualização em smartphones, tablets e desktops, incluindo uma barra de navegação fixa no mobile para facilitar o acesso.
- **Geração de PDF:**
  - **Manual Completo:** Botão dedicado para converter todo o manual em um arquivo PDF formatado para impressão.
  - **Checklist de Eventos:** Opção de imprimir apenas a lista de verificação para uso operacional durante eventos.
- **Navegação Inteligente:** Sidebar lateral com âncoras para acesso rápido a todas as 8 seções do manual.
- **Checklist Interativo:** Lista de tarefas para organização de eventos com salvamento de progresso visual (via interface).

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3:** Estilização avançada com Variáveis CSS (Design Tokens), Flexbox, Grid e animações de scroll.
- **JavaScript (Vanilla):** Lógica de navegação, animações de fade-in e sistema de impressão customizado.

## 📁 Estrutura do Projeto

- `index.html`: Arquivo principal contendo toda a estrutura, estilos e lógica da aplicação.
- `NOVOS_TOPICOS.md`: Documento de referência com a liturgia e conteúdos brutos (para consulta técnica).

## 📖 Como Visualizar

Basta abrir o arquivo `index.html` em qualquer navegador moderno. Para gerar o PDF, utilize o botão **"Download em PDF"** no topo da página ou a função de impressão do navegador (Ctrl+P).
